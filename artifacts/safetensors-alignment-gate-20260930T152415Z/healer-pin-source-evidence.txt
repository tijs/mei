=== Flag semantics that explain the 2026-09-06 heal ===
91fed8be: `if isDisabledFlag(rawEnabled) { return }`; the old helper treats only `0`, `false`, `no`, and `off` as disabled, so an unset variable does not disable healing.
654eb455 and fef563a5: `isEnabledFlag` returns true only for `1`, `true`, `yes`, or `on`; unset/empty values keep healing off.
fef563a5: `healBundleIfEligible` first requires `authorization == .directUserSend`, whose default in `LoadConfiguration` is `.disabled`.
