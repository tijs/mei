# Security policy

Please do not report security issues in public GitHub issues.

Until a dedicated private advisory workflow is configured, contact the
maintainer through the contact method listed on the maintainer's GitHub
profile. Include a minimal reproduction, affected commit or release, and
whether the issue requires a local model, server access, or a crafted HTTP
request.

Do not include API keys, access tokens, model-provider credentials, private
prompts, or personal data in reports.

Mei is intended for local use. Do not bind the server to a public interface
without adding authentication and reviewing the threat model first.
